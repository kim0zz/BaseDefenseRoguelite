# Detonator — wycofany z kitu L1

Ręczny Detonator (`bomberman_detonator`, `SkillShapeType.DetonateOwned`) **nie** jest już umiejętnością podstawową Bombera.

Slot 2: [`wybuchowy_odskok.md`](wybuchowy_odskok.md).

Główna bomba i ładunek z odskoku wybuchają na loncie. API `DetonateAllDetonatable` zostaje w rejestrze (FIFO cap, testy, ewentualny talent), ale nie ma przycisku w kitcie.
