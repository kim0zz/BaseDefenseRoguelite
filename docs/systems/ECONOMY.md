# Economy

## Status
**FROZEN dla logiki, OPEN dla cen**

## Trzy warstwy progresji
1. wspólny EXP → poziomy całej drużyny,
2. indywidualny loot → build postaci,
3. wspólna kasa → rozwój/naprawa bazy.

## Źródła kasy
Każdy typ wroga ma przypisaną wartość:
- zwykły: mała,
- trudniejszy/specjalny: większa,
- Carrier: bardzo duża,
- elita: duża.

## Wydawanie
Tylko między falami:
- naprawa wież,
- ulepszenie wież,
- leczenie bazy.
