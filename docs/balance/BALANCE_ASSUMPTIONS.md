# Balance Assumptions

## Status
**DRAFT**

1. Pojedynczy podstawowy przeciwnik nie jest dużym zagrożeniem; zagrożenie tworzy grupa.
2. Fala 1 ma być "papierowa".
3. Fale 2–4 mają już wymagać normalnej walki.
4. Po bossie 5 następuje wyraźny skok presji.
5. Build bez synergii powinien zacząć cierpieć przed końcem runu.
6. Dobry build ma dawać wyraźne poczucie mocy, ale nie usuwać mechanik bossów.
7. Boss nie może być czystym testem DPS.
8. Talent capstone powinien wyraźnie zmienić sposób grania.
9. Build off-meta może być słabszy na początku, ale musi mieć realny win condition.
10. Balance Agent ma flagować odchylenia, nie samodzielnie zmieniać FROZEN designu.
