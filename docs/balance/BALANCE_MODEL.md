# Balance Model

## Status
**DRAFT / metodologia przyjęta**

## Cel
Balansujemy doświadczenie gracza, nie same liczby.

## Główne miary
- DPS — obrażenia na sekundę.
- TTK — czas potrzebny do zabicia celu.
- EHP — efektywna wytrzymałość.
- kontrola tłumu,
- zasięg i bezpieczeństwo,
- wartość drużynowa,
- presja fali.

## Benchmark
Jamie lvl 1, atak podstawowy (historycznie miecz 10 / 0,8 s) = jednostka referencyjna 100%.

## Podstawowy mob fala 1
Powinien umrzeć dokładnie po 2 normalnych trafieniach ataku podstawowego Jamiego.

## Power budget talentów — DRAFT
- lvl 2: ~20–25% skoku efektywnej mocy,
- lvl 3: ~25–30%,
- lvl 4: ~25–30%,
- lvl 5: ~35–45%.

Nie oznacza to czystego +X% dmg. Wartość pochodzi ze zmiany umiejętności (kontrola, kształt, warunek, mobilność itd.).

## Rzadkość
System common/rare jest **poza MVP**. Skok mocy = talent jakościowy, nie loot.

## Skalowanie trudności
Presja ma rosnąć przez:
- liczbę wrogów,
- tempo spawnu,
- nowe typy,
- więcej elit,
- HP,
- obrażenia,
- nacisk na struktury.

Nie skalujemy wyłącznie HP.
