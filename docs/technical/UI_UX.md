# UI / UX

## Status
**FROZEN dla zakresu informacji, DRAFT dla layoutu**

HUD podczas fali musi pokazywać:
- własne HP,
- stan pozostałych graczy,
- HP bazy,
- czas fali,
- wspólny EXP,
- wspólną kasę,
- respawn timer,
- atak podstawowy i umiejętności (czas odnowienia / ładunki),
- ważne efekty statusowe.

## Level-up
- pełny pause,
- każdy gracz wybiera własny talent,
- każdy ma jasny status wyboru,
- gra wraca dopiero po zatwierdzeniu przez wszystkich aktywnych graczy.

## Między falami
- panel zarządzania bazą,
- brak slotów broni i przedmiotów,
- brak wymiany ekwipunku.

## Etapy
M0–M3: funkcjonalny placeholder UI.
M5–M6: pierwszy system UI/UX (historycznie inventory — do wyłączenia w M7.5).
M7.5: HUD umiejętności.
M9: polish, animacje, przejścia, finalne ikony i poprawki z playtestów.

## DRAFT — Combat Playability / kit

Przy ataku podstawowym HUD może pokazywać efektywne obrażenia i interwał (po talentach). Przy umiejętnościach — ikona i czas odnowienia. Bez pełnego arkusza statystyk.
