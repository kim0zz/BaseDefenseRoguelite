# Visual Feedback Checklist

## Status
**FROZEN jako checklista jakości**

Verifier sprawdza:

## Walka
- czy widać start ataku i przygotowanie umiejętności,
- czy moment trafienia jest czytelny,
- czy widać kto dostał obrażenia,
- czy atak podstawowy i umiejętności różnią się feelingiem,
- czy zapowiedź obszaru umiejętności jest czytelna przed trafieniem,
- czy efekty nie zasłaniają walki.

## Gracz
- niski HP jest czytelny,
- śmierć jest jednoznaczna,
- respawn timer jest widoczny,
- gracze są łatwi do odróżnienia,
- czas odnowienia umiejętności da się odczytać bez konsoli.

## Baza i wieże
- uszkodzenia są widoczne,
- niski HP bazy jest komunikowany,
- ulepszenie wieży daje rozpoznawalną zmianę.

## Bossowie
- duże mechaniki mają czytelne zapowiedzi,
- strefy zagrożenia są czytelne,
- fazy da się rozpoznać.

## Wynik
PASS / FAIL / NEEDS PLAYTEST.

Game feel nie może być PASS wyłącznie na podstawie kodu.
